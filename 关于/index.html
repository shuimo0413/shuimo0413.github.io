关于

阅读时长: 1 分钟

你好，我是 shuimo，一名专注于 Java 后端开发，同时具备前端与物联网技术能力的开发者。

  • 后端开发：以 Java 为核心技术栈，熟练使用 Spring Cloud、Spring Boot、MyBatis、MyBatis-Plus 等框架，能够高效构建稳定的分布式服务与业务系统，同时熟悉 MySQL、Redis 等数据存储与缓存方案。
  • 物联网方向：掌握 MQTT 协议，熟悉 ESP32/ESP8266 等硬件设备的通信开发，能够实现设备与云端的数据交互、远程控制等物联网场景。
  • 前端开发：具备 Vue、JavaScript、HTML/CSS 基础，可独立完成前端页面开发与数据展示，例如基于 Vue + MQTT 的物联网上位机前端项目。
  • 工具与工程化：熟练使用 Git、Docker、Postman 等开发与运维工具，具备良好的工程化开发与协作能力。
